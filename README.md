# Advanced Machine Learning

Raccolta di esercitazioni e progetti sviluppati durante il corso di **Advanced Machine Learning**.

La repository contiene diversi esperimenti pratici di Machine Learning e Deep Learning, realizzati utilizzando differenti dataset e architetture di reti neurali.

## Progetti
- `adult_income/`: Classificazione del reddito attraverso modelli di Machine Learning.
- `fashion-mnist`: Due problemi differenti su classificazione delle immagini sul dataset Fashion-MNIST.  
- `cifar10/`: Esperimento di classificazione delle immagini sul dataset CIFAR-10.  
- `CNN-mnist/`: Applicazione di reti neurali convoluzionali al dataset MNIST.  
- `RNN-frankenstein/`: Esperimenti con reti neurali applicati al testo di Frankenstein.  

## Contenuti

Ogni progetto contiene, a seconda dell'esercitazione:

- Notebook Jupyter con il codice e gli esperimenti.
- Grafici e visualizzazioni dei risultati.
- Relazioni in formato PDF.
- Pesi dei modelli addestrati, dove disponibili.

## Tecnologie utilizzate

- **Python** — implementazione degli esperimenti.
- **Jupyter Notebook** — sviluppo e documentazione del codice.
- **Librerie di Machine Learning e Deep Learning** — addestramento e valutazione dei modelli.
- **Matplotlib** — visualizzazione dei risultati.
